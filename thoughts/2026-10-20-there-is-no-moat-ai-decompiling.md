# There Is No Moat: AI-Supercharged Software Decompiling

**Date:** 2026-10-20
**Source:** https://www.linkedin.com/pulse/moat-brave-new-world-ai-supercharged-software-noah-h6kqc
**Author:** Noah Kadner
**Tags:** #ai #decompiling #open-source #software-industry #moat #reverse-engineering

## Premise

AI agents can now decompile compiled software back into readable, editable source code in hours/days — work that used to take specialist teams months or years. The decades-old "secrecy moat" that protected closed-source software is gone for anything that runs on the user's machine.

## Key Points

- **Space Quest (1986) rebuilt**: Kadner used Claude to decompile the original Sierra game and convert it pixel-for-pixel into a modern web app.
- **Call of Duty: Black Ops** browser version built the same way (via Kotaku).
- **Adobe hit directly**: Brandon Thomas released ArtCraft — free open-source recreations of seven Adobe Creative Cloud apps.
- **ESR (Eric S. Raymond)**: "There is no longer a secrecy moat around almost any software at all." Any app or firmware image is "as transparent as glass" — it won't keep secrets longer than it takes for someone to throw an LLM at it. He did not foresee closed source being "wiped out in a technoapocalypse."
- **Scale of exposure**: Gartner forecasts $1.47T worldwide software spending in 2026; Adobe alone took $23.77B last fiscal year, mostly from apps that run on customers' own machines.
- **Buffett's moat framing**: "A moat that must be continuously rebuilt will eventually be no moat at all." For software companies the moat was code secrecy — AI drained it.

## What Still Holds

- **Cloud-hosted software** stays hidden — code never reaches the user.
- **Hardware encryption** not yet publicly broken (current Xbox, Nintendo Switch 2) stays out of reach.
- **Heavy anti-tamper** slows the work but doesn't stop it.

## Counterpoint (from the comments)

Vibe-coded software is still hard to manage without a team — like a solo filmmaker who can write/direct/edit but may not produce something good or seen. But for tinkerers, it's a whole new world.

## Why It Matters

- Shifts value from *owning code* to *owning distribution, data, brand, and cloud services*.
- Implications for Apple, Adobe, Microsoft — any company whose product is installed locally.
- Strengthens the case for open-source and for SaaS/cloud as the only remaining moat.
