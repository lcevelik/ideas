## Technical Workflow

### Pre-Production (30 Days or Less)

```
Day 1-3: Script Analysis
    └── AI reads script → character breakdowns, location lists, prop lists

Day 4-10: Storyboarding
    └── AI generates storyboards for every shot
    └── Director reviews, refines with department heads
    └── PFX reviews for technical feasibility

Day 11-20: First Frames & Location Builds
    └── AI generates photoreal first frame for every shot
    └── Location builds: architectural perfection for each environment
    └── AR system projects over gray stage for director review

Day 21-25: Scheduling & Breakdown
    └── AI generates shot-by-shot schedule
    └── Sides, call sheets, VFX breakdown per shot
    └── Coordinates actor/crew schedules for efficiency

Day 26-30: Full Movie Preview
    └── Director watches entire movie (AI-generated, not release quality)
    └── "100% certainty you never had before"
    └── Final adjustments before production
```

### Production (70% Time Reduction)

```
Gray Stage Setup:
    ├── Consistent lighting (UPS provides, doesn't change)
    ├── Blocking shapes on walls (AI-optimized)
    ├── Multiple cameras (Sony provides if resident)
    └── AR system active (director sees final environment)

Daily Workflow:
    ├── 5-20 minute turnarounds (no set building)
    ├── AI tells crew which props to use physically
    ├── Director directs normally (standard cameras)
    ├── All focus on actor performance
    └── 130+ day players shot in under 2 days

Key Metrics (from validated productions):
    ├── 72-day shoot → 21 days
    ├── 213 locations → 1 gray stage
    ├── $120-130M below-the-line → $40M (now $25M)
    └── 10 minutes shown at Cannes 2 weeks after wrap
```

### Post-Production (PFX Handles)

```
AI World Generation (Prague Studios):
    ├── Build environment around captured actors
    ├── Lighting/color matching
    ├── Gaussian Splatting for spatial consistency
    └── Fast draft render (editorial starts immediately)

Traditional Post (PFX):
    ├── Final pixel rendering (overnight, 4K 16-bit)
    ├── Compositing
    ├── Color grading
    ├── Sound design and mix
    └── Delivery

Key Advantage:
    ├── Can modify anything: lighting, locations, environments
    ├── Director watches scene, says "change the city look"
    ├── Within hours, no physical rebuild needed
    └── Would have cost $5-7M to do practically
```
